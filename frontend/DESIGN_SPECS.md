# Design Specifications from Figma

## Color Palette
Based on the homepage screenshot analysis:
- Primary Blue: #2563eb (or similar blue tone)
- White: #FFFFFF
- Light Gray Background: #F5F5F5 / #FAFAFA
- Dark Text: #1F2937
- Gray Text: #6B7280
- Border Gray: #E5E7EB

## Typography
- Font Family: Inter (already configured)
- Heading sizes: Large (32-48px), Medium (24-32px), Small (18-24px)
- Body text: 14-16px
- Small text: 12-14px

## Layout Structure
1. **Navbar**: Fixed top, white background, shadow
   - Logo (left)
   - Navigation menu (center)
   - Search bar
   - Icons: Cart, User (right)

2. **Hero/Banner Section**: 
   - Large promotional banner
   - CTA buttons
   - Featured content

3. **Product Sections**:
   - Category-based sections (Tech, Interior, Clothing)
   - Grid layout (4-5 columns on desktop)
   - Product cards with images, titles, prices

4. **Footer**:
   - Multi-column layout
   - Links and information
   - Newsletter signup

## Component Styles
- Cards: White background, subtle shadow, rounded corners
- Buttons: Solid colors, rounded, medium padding
- Images: Aspect ratio maintained, object-fit cover
- Spacing: Consistent padding and margins (16px, 24px, 32px)
